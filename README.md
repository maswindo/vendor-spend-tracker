# Vendor Spend & Invoice Tracker

A data analysis and reporting tool designed to track vendor invoices, analyze company spending trends, and highlight cost-saving opportunities using Excel and Tableau.

---

## 📦 Overview

This project automates the logging and analysis of all vendor purchases over a 12-month span. It captures each invoice line-item and aggregates data by vendor, product, location, and time period. The output is designed for Excel-based summaries and Tableau dashboarding.

---

## 🔍 Key Capabilities

- Logs every invoice line item with product, cost, and location
- Tracks total and monthly spend by vendor
- Identifies top materials by cost and usage
- Flags high-cost vendors or duplicate purchases
- Powers Tableau dashboards with clean, structured data

---

## 🧰 Tools & Tech

| Tool            | Use Case                                   |
